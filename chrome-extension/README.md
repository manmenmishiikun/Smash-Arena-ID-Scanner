# Smash Arena ID Bridge（Chrome 拡張）

**Smash Arena ID Scanner**（デスクトップ）が `127.0.0.1` で配信する **Server-Sent Events（SSE）** に接続し、受け取った **部屋コード** を対戦サイトの入力欄へ反映する補助拡張です。

- **主対象（v1.2）**: [`smatch-jp.com`](https://smatch-jp.com/) のレーティング対戦ルーム（`/rate/<数>/`）— **自動ペーストのみ**（[`content-smatch.js`](content-smatch.js)）
- **互換**: 旧 `smashmate.net` 向けのキー操作・自動クリック付きスクリプト（[`content.js`](content.js)）は別注入のまま残しています

## 重要な前提（混同禁止）

- **SSE の `data` 行**は、ゲーム画面 OCR 由来の **部屋コード**（デスクトップが確定した文字列）です。
- **URL パスに含まれる数字**（例: `https://smatch-jp.com/rate/27847/` の `27847`）は **スマッチ内の対戦ルーム番号**（旧スマメイトではプロフィール側 ID）であり、**ゲームの 5 文字部屋コードではありません**。

## 自動化の範囲（やること／やらないこと）

| サイト | 行うこと | 行わないこと（第1段） |
|--------|----------|----------------------|
| **スマッチ** | `form#arenaForm input[name="arena_id"]` へ値を書き、短いアウトライン表示。空欄時は先頭 1 回の SSE をスキップ | 「設定」submit の自動 click、キーボード補助、パスワード入力 |
| **スマメイト（互換）** | 従来どおり `room_matching_id` への反映。オプション ON 時のみ `matching_post_btn` の click、Enter/Space 等 | サイトの確認ダイアログの自動 OK（人が操作） |

同一部屋コードの再送は、直前と同じなら入力をスキップします。

## 対象ページ（それ以外では DOM を触りません）

- **スマッチ**: `https://smatch-jp.com/rate/*` → `shared-path.js` + `content-smatch.js`
- **スマメイト**: `https://smashmate.net/rate/*` → `shared-path.js` + `content.js`
- **部屋コードの自動入力**はさらに `location.pathname` が **`/rate/<数値>/` 形式**のときのみ（`isRateProfilePath`）。
- **SSE 接続**は拡張の **「PC アプリと連携する」** が ON かつ、**上記いずれかの rate URL タブが 1 つ以上あるときだけ**張ります。ホスト判定は `shared-path.js` の対応ホスト集合で行い、無関係な `/rate/<数>/` サイトでは SSE を張りません。

実サイトの URL が末尾スラッシュ付き／なしのどちらでも、上記パターンにマッチすれば動作します。

## ローカルブリッジとの合わせ方

- **URL**: `http://127.0.0.1:<ポート>/events`（パスは **`/events`** 固定）
- **ポート**: デスクトップの **「連携ポート」** と **拡張のオプションのポート**を **同じ値**にしてください。既定は **2206** ですが、**ハードコードせず**オプションで変更します。
- **デスクトップ側**: Arena Scan の **「と連携」** が ON かつ **OCR 監視中**のときだけ SSE が Listen されます。監視を止めるとストリームが切れます。

## SSE の読み方（Service Worker）

- **`EventSource`** は環境によって挙動差が出ることがあるため、本拡張では **`fetch` + `ReadableStream`（`getReader`）** で本文を読み、**`data: ...` と空行区切り**をパースしています。切断検知・再接続間隔の制御もしやすいです。

## 切断・再接続

- デスクトップで監視停止・連携 OFF・アプリ終了などで **SSE が切れます**。
- 拡張は **指数バックオフ**（初期 1 秒、最大 30 秒）で **再接続**を試みます（接続 ON かつ **rate プロフィールタブが少なくとも 1 つある間**）。
- ツールバーアイコンの **バッジ**: 接続できているとき `OK`（緑系）、エラー時 `!`（赤系）、接続 OFF 時は非表示です。

## 権限・プライバシー

- **`http://127.0.0.1/*`**: ローカル SSE への接続のみ。
- **`https://smatch-jp.com/rate/*`** / **`https://smashmate.net/rate/*`**: 対象タブへメッセージを送り、コンテンツスクリプトで入力を更新するため（スコープ最小化）。
- **収集・外部送信**: 部屋コードを **当拡張のサーバーに送る処理はありません**。各対戦サイトの利用規約・ポリシー・サーバー負荷は **利用者の責任**です。本拡張は **一般目的のローカル連携クライアント**として提供します。

Chrome Web Store に公開する場合は、上記の権限理由とデータ非送信を **ストアの説明文**や **プライバシーポリシー**に書くと審査に通りやすくなります。

## 配布・動作環境

- **拡張単体**: ネイティブコードなし。**Chrome / Edge 等 Chromium（Manifest V3）** が動く環境で、**CPU/GPU を特別に要求しません**。
- **配布**: Chrome Web Store、または ZIP を **開発者モードで「パッケージ化されていない拡張機能を読み込む」** など。
- **OCR デスクトップアプリ**は別リポジトリで **Windows 前提**のため、**部屋コード生成まで含めた一式**は OS が分かれます。拡張のみならブラウザさえあれば利用できます。

## インストール（開発）

1. Chrome で `chrome://extensions` を開く。
2. 「デベロッパーモード」を ON。
3. 「パッケージ化されていない拡張機能を読み込む」で、この `chrome-extension` フォルダを指定。
4. **ツールバーの拡張アイコンをクリック**すると設定パネル（ポップアップ）が開きます。**PC アプリと連携する**・**詳細（ポート番号）**・**使い方**から設定できます（`chrome://extensions` の「拡張機能のオプション」からも同じ画面を開けます）。変更は自動保存です。アイコンがパズルメニュー内だけのときは、パズルアイコンから本拡張を **ピン留め**すると常に表示されます。

### 初回セットアップ（3ステップ）

1. デスクトップの Arena Scan で **「と連携」ON + 監視開始**。
2. 拡張の **詳細（ポート番号）** で、デスクトップ側と **同じ番号**にする（既定 2206）。
3. スマッチの **対戦ルーム**ページ（`https://smatch-jp.com/rate/<数値>/` 形式）を開く。

ポップアップ上部の **状態表示**と、ツールバーアイコンに **ホバー**したときの一行説明で、接続の理由が分かります。詳しい手順・トラブルは拡張内 **使い方**（`guide.html`）または本 README の技術欄を参照してください。

## 手動確認の目安

- デスクトップ: **「と連携」** ON、**詳細（歯車）** でポート例 2206、**監視中**。
- 拡張: **PC アプリと連携する** ON、**詳細**で同じポート（入力は自動保存）。
- `https://smatch-jp.com/rate/<数値>/`（ホストで部屋 ID 未設定）を開き、OCR が部屋コードを確定すると `arena_id` 欄に反映されること。**「設定」は人が押す**（第1段）。
- 監視停止後、バッジがエラー側に寄る／再接続を繰り返すこと。
- **対象外 URL** では入力が変わらないこと。
